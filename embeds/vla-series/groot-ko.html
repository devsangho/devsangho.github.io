4부작 내내 붙들었던 질문은 하나였다. VLM이 이해한 장면 정보를 어떤 형태로 행동 모델에 전달하는가? GR00T N1은 NVIDIA가 공개한 휴머노이드용 범용 모델이고, 이 질문에 π0와는 다른 답을 낸다.

그래서 번외편으로 따로 다룬다. 행동을 만드는 원리는 3편의 flow matching과 같다. 달라지는 것은 두 신경망을 잇는 방식, 두 신경망을 돌리는 속도, 그리고 데이터를 모으는 방식이다. 구조와 수치는 논문 원문에서 확인했다.

1문제: 휴머노이드에는 데이터가 없다

언어모델은 인터넷 규모의 텍스트로 사전학습한다. 휴머노이드 로봇에는 그런 데이터가 없다. 논문은 하드웨어 하나에서 모을 수 있는 데이터가 필요한 양보다 "자릿수 단위로" 작다고 쓴다.

여러 로봇의 데이터를 합치는 방법도 있다. 1편의 OpenVLA가 Open X-Embodiment로 그렇게 했다. 하지만 로봇마다 몸의 구조, 센서, 행동 공간이 달라서 하나의 데이터셋이라기보다 서로 떨어진 "데이터 섬"에 가깝다. 실제 휴머노이드로 직접 모으는 데이터는 비싸다.

GR00T N1의 답은 두 갈래다. 다른 몸과 라벨 없는 영상까지 받아들일 수 있는 모델 구조를 만들고, 부족한 로봇 데이터를 시뮬레이션과 생성 영상으로 채운다. 아래 2~4장은 모델을, 5장은 데이터를 다룬다.

2두 시스템: System 2와 System 1

GR00T N1은 이해를 맡는 System 2와 행동을 맡는 System 1으로 나뉜다. 이름은 사람의 사고를 느리고 신중한 체계와 빠르고 직관적인 체계로 나누는 비유에서 왔다.

System 2는 NVIDIA의 Eagle-2 VLM이다. 이미지 인코더는 SigLIP-2, 언어모델은 SmolLM2다. 4편의 SmolVLA가 쓴 SmolVLM-2와 같은 언어모델 계열이고, 이미지를 pixel shuffle로 프레임당 64토큰까지 줄이는 것도 같다.

흥미로운 선택이 하나 있다. VLM의 마지막 층이 아니라 LLM의 12번째 층 출력을 System 1에 넘긴다. 논문은 중간 층 특징이 마지막 층보다 추론도 빠르고 성공률도 높았다고 쓴다. 다만 이 비교의 수치는 공개하지 않았다. SmolVLA가 VLM의 앞쪽 절반만 쓴 것과 같은 방향의 관찰이다.

두 시스템은 다른 속도로 돈다. 논문 기준으로 System 2는 L40 GPU에서 10Hz로 장면을 읽고, System 1은 120Hz로 행동을 내놓는다.

바로잡기System 1이 Diffusion Transformer(DiT)라고 해서 3편의 flow matching과 다른 생성 방식이라고 생각하기 쉽다. DiT는 네트워크 구조의 이름이고, flow matching은 그 네트워크를 학습시키는 목표다. 서로 다른 층위의 개념이고, GR00T N1은 DiT 구조로 flow matching을 학습한다.

DiT에서 flow의 시간 τ는 adaptive layer normalization(AdaLN)으로 들어간다. τ에서 정규화 층의 스케일과 시프트를 만들어 특징을 조절하는 방식이다. 2편에서 OFT가 언어로 시각 특징을 조절할 때 쓴 FiLM과 같은 아이디어다.

3π0와 무엇이 다른가: 만나는 위치

π0와 GR00T N1은 둘 다 VLM과 별도의 행동 트랜스포머를 쓰고, 둘 다 flow matching으로 action chunk를 만든다. 큰 틀은 같다. 차이는 두 신경망이 만나는 위치에 있다.

3편에서 본 것처럼 π0는 두 가중치의 토큰을 한 트랜스포머의 self-attention 안에 넣는다. 그래서 행동 토큰은 층마다 같은 층의 VLM 표현을 읽는다. GR00T N1은 VLM이 먼저 계산을 끝내고, 그 결과 토큰을 System 1의 cross-attention 층이 Key와 Value로 읽는다. 행동 토큰 쪽에서 보면 식은 같다.

$$H_A'=\operatorname{softmax}\!\left(\frac{Q_A K_{VL}^\top}{\sqrt d}\right)V_{VL}$$

달라지는 것은 \(K_{VL}, V_{VL}\)이 어디서 오느냐다. π0에서는 행동 트랜스포머의 층마다 VLM의 같은 층이 제공하고, GR00T N1에서는 12번째 층의 출력 하나가 모든 cross-attention 층에 공통으로 쓰인다.

바로잡기"GR00T는 VLM 정보를 벡터 하나로 요약해 넘긴다"는 설명은 지나친 단순화다. 넘어가는 것은 이미지와 언어의 토큰 여러 개이고, System 1은 그 토큰들을 attention으로 골라 읽는다. 차이는 정보를 압축하느냐가 아니라 어느 깊이의 표현을 어떤 경로로 읽느냐다.

GR00T의 행동 모델 크기는 논문의 2.2B와 1.34B에서 계산한 값이다. 세 모델은 데이터와 로봇이 모두 달라 이 표만으로 연결 방식의 우열을 가릴 수 없다.

구조에서 예상할 수 있는 장단점은 있다. 결합형은 행동을 만드는 동안 세밀한 시각 정보를 층마다 직접 쓸 수 있다. 분리형은 두 모듈을 따로 최적화하고 다른 속도로 돌리기 쉽지만, 넘겨받는 표현에 행동에 필요한 정보가 충분히 담겨야 한다. 어느 쪽이 나은지는 같은 VLM, 같은 행동 모델, 같은 데이터에서 연결 방식만 바꾼 실험으로 확인해야 한다. 4부작 마지막에 남긴 "결합 강도" 질문이 바로 이것이다.

4몸이 달라도 하나의 모델

단일 팔, 양팔, 휴머노이드는 상태와 행동의 차원이 모두 다르다. 3편의 π0는 가장 큰 18차원에 맞춰 나머지를 0으로 채웠다. GR00T N1은 System 1의 바깥에 몸마다 다른 작은 MLP를 둔다.

상태 인코더와 행동 인코더가 각 로봇의 값을 공통 차원으로 투영하고, 행동 디코더가 마지막 \(H\)개 토큰을 다시 그 로봇의 행동으로 바꾼다. 행동 인코더는 π0처럼 flow의 시간 τ도 함께 받는다. 가운데의 DiT는 모든 몸이 공유한다.

이 구조 덕분에 행동 라벨이 없는 사람 영상도 학습에 들어간다. 다음 장에서 볼 잠재 행동을 라벨로 붙여 "LAPA"라는 하나의 몸처럼 취급한다.

5데이터 피라미드

모델이 다양한 데이터를 받을 수 있게 되었으니, 이제 데이터를 쌓을 차례다. 논문은 이를 피라미드로 그린다. 바닥은 웹 데이터와 사람 영상, 가운데는 시뮬레이션과 생성 영상, 꼭대기는 실제 로봇 데이터다.

라벨 없는 영상에 행동 붙이기

사람 영상과 생성 영상에는 로봇 행동이 없다. 논문은 두 가지 방법으로 라벨을 만든다.

  • 잠재 행동 (LAPA): 현재 프레임과 \(H\) 스텝 뒤의 프레임을 VQ-VAE로 압축해, 그 사이의 변화를 나타내는 임베딩을 행동 대신 쓴다.
  • 역동역학 모델 (IDM): 두 프레임을 보고 그 사이의 action chunk를 추정하는 모델을 따로 학습해, 가짜 행동을 붙인다.

데이터를 만들어 내기

시뮬레이션에서는 DexMimicGen으로 수십 개의 시연을 수만 개로 불렸다. 사전학습에는 54개 조합에서 조합당 10,000개씩, 총 54만 개의 시연이 들어갔다. 생성 영상 쪽에서는 영상 생성 모델 WAN2.1을 실제 데이터로 LoRA 파인튜닝해, GR-1 원격조작 약 88시간을 약 827시간의 영상으로 늘렸다.

효과는 확인됐다. RoboCasa에서 신경망 궤적을 더하자 시연 30, 100, 300개 조건에서 성공률이 각각 4.2, 8.8, 6.8포인트 올랐고, 실제 GR-1의 8개 작업에서는 평균 5.8포인트 올랐다. 라벨 방식은 시연이 적을 때 잠재 행동이 조금 낫고, 100개 이상에서는 IDM이 앞섰다.

6학습과 추론

flow matching의 식은 3편의 π0와 같은 형태이고, 시간 τ도 π0와 같은 Beta 분포(\(s=0.999\))에서 뽑는다.

$$A^\tau=\tau A+(1-\tau)\epsilon,\qquad \mathcal L=\big\|V_\theta(\phi_t,A^\tau,q_t)-(\epsilon-A)\big\|^2$$

메모4편의 SmolVLA와 같은 표기 문제가 있다. 이 식대로라면 \(dA^\tau/d\tau=A-\epsilon\)이라 목표와 부호가 반대다. 논문만으로는 시간 방향의 관례가 정해지지 않으니, 구현할 때는 코드에서 확인하는 게 좋다.

지연16개 행동 chunk 생성에 63.9ms (L40, bf16)
보조 손실목표 물체의 위치를 맞히는 검출 손실을 함께 학습

GR00T N1이 다섯 모델 중 가장 분명하게 보여 주는 것은 "모델 구조와 데이터 전략은 함께 설계된다"는 점이다. 몸마다 다른 MLP와 잠재 행동이 있어야 사람 영상과 생성 영상이 학습에 들어오고, 그 데이터가 있어야 2.2B 모델을 휴머노이드에 맞게 사전학습할 수 있다.

논문이 밝힌 한계도 분명하다. 평가는 짧은 탁상 조작에 집중되어 있고, 이동과 조작을 함께 하는 긴 작업은 앞으로의 과제다. 합성 데이터는 다양한 반사실 상황과 물리를 아직 충분히 담지 못한다. 이후 N1.5 같은 후속 버전이 다른 연구들의 비교 대상으로 쓰이고 있지만, 이 글은 원 논문이 있는 N1만 다뤘다.
